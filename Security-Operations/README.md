# Security Operations (SecOps)

This section covers the core concepts of Security Operations Centers (SOC), continuous monitoring, and the tools used to detect and analyze infrastructure threats.

### Key Areas of Study:
* **SIEM & Log Management** — Centralizing logs, creating correlation rules, and analyzing alerts.
* **Threat Detection** — Monitoring network traffic, endpoint behavior, and system anomalies.
* **Vulnerability Management** — Asset discovery, vulnerability scanning, and risk prioritization.
