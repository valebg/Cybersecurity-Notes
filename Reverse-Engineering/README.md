# Reverse Engineering

This section focuses on the fundamentals of software reverse engineering, malware analysis, and understanding compiled binaries.

### Key Areas of Study:
* **Binary Analysis** — Understanding assembly language (x86/x64), CPU registers, and memory layouts.
* **Static & Dynamic Analysis** — Examining code behavior using tools like Ghidra, IDA Pro, and debuggers (x64dbg/GDB).
* **Code Decompilation** — Reconstructing high-level logic from compiled source structures to identify potential security vulnerabilities.
