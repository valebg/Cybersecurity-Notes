# Лабораторная работа: Челлендж "Squid Game" (Steganography & Digital Forensics)

Решение стеганографического челленджа в стиле CTF по мотивам сериала "Игра в кальмара". В ходе работы были применены методы анализа метаданных, извлечения скрытых контейнеров и анализа битовых плоскостей изображения (LSB).

> **Примечание по безопасности (Writeup Policy):** В целях соблюдения правил платформы и сохранения интриги для других участников, все ключевые ответы и финальный флаг частично скрыты под маску `*`.

---

## 🛠 Использованные инструменты
* **Steghide** — утилита для скрытия/извлечения данных в JPEG/BMP/WAV с использованием пароля.
* **zsteg** — мощный инструмент для автоматического поиска скрытых данных в PNG/BMP файлах (анализ LSB).
* **Python 3** — для автоматизации анализа пикселей.

## 🚀 Пошаговое решение (Writeup)

### Шаг 1: Сбор базовой информации
По условию задачи на руках был один файл: `Invitation Card.jpg`. 
Первым делом на основе открытых источников (OSINT) был найден оригинальный телефонный номер с визитки из сериала, который послужил паролем к контейнеру:
* **Найденный номер телефона:** `8650****` (8 цифр)

### Шаг 2: Извлечение скрытого контейнера из JPG
Используя утилиту `steghide` и полученный на предыдущем шаге номер телефона в качестве парольной фразы (passphrase), извлекаем вложенный файл:
```bash
steghide extract -sf "Invitation Card.jpg"
Имя извлеченного файла: Da******.png

Шаг 3: Стеганоанализ PNG (Поиск подсказки)
Для анализа извлеченного PNG-файла была использована утилита автоматического сканирования плоскостей zsteg:

Bash
zsteg -a Dalgona.png
В ходе анализа структуры и битовых плоскостей изображения на одном из каналов была обнаружена текстовая подсказка (Hint text), указывающая на целевой метод скрытия:

Текст-подсказка: R P**** (Указывает на конкретный цветовой канал)
