# Incident Response

This repository section focuses on the methodologies, phases, and practical workflows for identifying, containing, and eradicating security breaches.

### Key Areas of Study:
* **IR Lifecycle** — Preparation, Detection & Analysis, Containment, Eradication, and Post-Incident Activity (NIST / PICERL framework).
* **Live Response & Triage** — Collecting volatile evidence from live systems under analysis.
* **Log Analysis** — Identifying indicators of compromise (IoCs) across authentication, application, and system logs.
