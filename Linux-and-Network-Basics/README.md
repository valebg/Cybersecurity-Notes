# Linux and Network Basics

This section contains fundamental knowledge regarding Linux system administration, command-line operations, and core networking concepts required for security analysis.

### Core Topics Covered:
* **Linux CLI & Sysadmin** — Essential commands, file permissions, and user management.
* **Network Analysis** — Packet inspection and traffic analysis using **Wireshark** and tcpdump.
* **Network Protocols** — Deep dive into TCP/IP stack, DNS, DHCP, and HTTP/HTTPS routing.
